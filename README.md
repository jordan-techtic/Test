# Marketing Content Calendar

Vite + React + TypeScript frontend for marketing team members.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — typecheck and production build
- `npm run lint` — ESLint
- `npm run format` — Prettier
- `npm test` — Jest

## Environment

Copy `.env.example` to `.env`. The client reads `VITE_API_BASE_URL` (default host already includes `/api`). Request paths are `/v1/...`.
